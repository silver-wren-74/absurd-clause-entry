Entry for the make.fun competition
[The Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1)
($2 prize pool, top 10 paid).

`main.py` writes a single original English sentence — an absurd clause
that could hide deep inside a terms-of-service agreement — to
`/output/entry.txt` (UTF-8, 1–200 characters, as the gate requires).

> You agree that any dispute will be settled by a duel between our CEOs
> at dawn, using pool noodles, in a parking lot of our choosing.

Run it with `python3 main.py`. It prints the character count and exits 0.
